# XPTouch Russian Version

Русская версия сенсорного экрана для управления 3D-принтерами Bambu Lab. Основная цель проекта - Bambu Lab P1S без штатного сенсорного экрана. Совместимые односопловые модели могут работать, но полностью не тестировались.

## Возможности

- мониторинг температуры, состояния, процента и слоя печати;
- отображение названия текущей модели на главном экране;
- управление паузой, остановкой, скоростью и подсветкой;
- работа с AMS и несколькими принтерами на 5-дюймовом экране;
- подключение через Bambu Cloud или LAN Only Mode;
- обновление прошивки по USB или по Wi-Fi из Visual Studio Code.

H2D и H2C пока не поддерживаются. Для P1S используется прошивка принтера до версии 1.7 включительно. Для новых версий используйте LAN Only Mode и учитывайте ограничения протокола Bambu Lab.

## Оборудование

Поддерживаются платы ESP32 с дисплеями 320x240, 480x320 и 800x480. Основные профили проекта:

- 2.8 дюйма: `env:esp32dev`;
- 5 дюймов: `env:esp32-s3dev`;
- 5 дюймов JC8048W550: ESP32-S3-DevKitC-1-N16R8 и настройка LCD из [docs/lcd-settings-5inch.md](docs/lcd-settings-5inch.md).

Нужны стабильное питание USB, microSD-карта FAT32 и кабель USB с передачей данных. Для некоторых плат потребуется драйвер CH340 или CP210x.

## Установка через Visual Studio Code

Браузерный онлайн-инсталлятор для прошивки не используется. Прошивка собирается и записывается из VS Code через PlatformIO.

1. Установите [Visual Studio Code](https://code.visualstudio.com/).
2. В VS Code установите расширение **PlatformIO IDE**.
3. Установите Python 3 и Node.js LTS.
4. Скачайте или клонируйте репозиторий и откройте его папку в VS Code.
5. Подключите XPTouch USB-кабелем с передачей данных.

Для ESP32-S3 установите описание платы:

```bash
mkdir -p ~/.platformio/boards
cp docs/boards/esp32-s3-devkitc1-n16r8.json ~/.platformio/boards/
```

В нижней панели PlatformIO выберите нужный environment, нажмите **Build**, затем **Upload**.

```bash
python3 -m platformio run -e esp32dev -t upload
python3 -m platformio run -e esp32-s3dev -t upload
```

## Обновление по Wi-Fi из VS Code

После первой прошивки по USB устройство запускает ArduinoOTA после подключения к Wi-Fi. Компьютер и XPTouch должны быть в одной сети.

1. Узнайте IP-адрес XPTouch на экране настроек.
2. В терминале VS Code задайте адрес:

```bash
export XTOUCH_OTA_IP=192.168.1.50
```

3. Выберите `Terminal > Run Task`, затем задачу **XPTouch: OTA 2.8** или **XPTouch: OTA 5.0**.
4. Либо выберите OTA environment в PlatformIO и нажмите кнопку **Upload**.

OTA-профили: `esp32dev-ota` для 2.8 дюйма и `esp32-s3dev-ota` для 5 дюймов. Не отключайте питание во время обновления. Если Wi-Fi недоступен, используйте USB Upload или microSD.

## Первоначальная настройка Wi-Fi и Bambu Lab

Для Cloud Mode создайте `provisioning.json` с параметрами сети и токеном Bambu Lab. Для LAN Only Mode используйте `xtouch.json` в корне microSD и включите LAN Only Mode на принтере. После загрузки конфигурации вставьте карту в XPTouch, включите устройство, выберите принтер и выполните калибровку сенсорной панели.

Chrome-расширение больше не используется для установки прошивки. Оно может понадобиться только для старого процесса получения provisioning-файлов, если вы не создаёте их вручную.

## Печать и модель

Название модели берётся из MQTT-поля `print.subtask_name` и показывается под именем принтера на главном экране. Длинные названия сокращаются многоточием, чтобы не перекрывать прогресс и состояние печати.

## Обновление с microSD

Это запасной способ, если USB и OTA недоступны. Скопируйте собранный `firmware.bin` в корень FAT32-карты, вставьте карту в устройство и перезапустите его. Не отключайте питание во время обновления. Для разработки предпочтительнее VS Code Upload.

Подробности о структуре проекта, пользовательской плате ESP32-S3 и сборочных скриптах находятся в [docs/develop.md](docs/develop.md). Конфигурация PlatformIO находится в [platformio.ini](platformio.ini).

